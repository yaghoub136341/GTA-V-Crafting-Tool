# GTA V Crafting Manager 🛠️

A professional C++ based crafting management system designed for GTA V modding environments. This tool handles complex crafting recipes, ingredient validation, and persistent data storage using JSON.

## ✨ Features

- **Dynamic Recipe Management**: Easily add, remove, and modify crafting recipes.
- **JSON Persistence**: All crafting data is stored in structured JSON format for easy editing and scalability.
- **Robust Architecture**: Built with Object-Oriented Programming (OOP) principles using `std::map` and `std::vector` for high performance.
- **Scalable Design**: Ready to be integrated into larger GTA V modding frameworks.

## 🛠️ Technical Stack

- **Language**: C++
- **Data Format**: JSON (via `nlohmann/json`)
- **Version Control**: Git & GitHub
